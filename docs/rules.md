# Актуальная редакция

Для новых партий используется Prison 0.3; спецификация и управление описаны в [prison03.md](prison03.md). Приведённые ниже записи сохраняют историю старой версии и не заменяют новые формулы.

---

# Исходные правила — черновик, не утверждённая спецификация

Материалы: архив «Настолка.zip»: книга v1.1, NPC codex, Настолка.docx и идентичная Настолка2.docx, мини-игры, 26 PNG. Картотека содержит индивидуальные статблоки, которые нельзя молча пересчитывать.
В v1.1 проверены в том числе формулы Word:
- четыре характеристики: Сила, Ловкость, Телосложение, Харизма;
- HP=(Телосложение+уровень)*2+броня;
- ОД=5+ceil(Ловкость/3), клетка 1 ОД, обычная атака 2 ОД;
- урон=кости оружия+ceil(подходящая характеристика/4);
- ближний: 2d12+Сила против 2d12+Ловкость, реакции защитника;
- дальний: 2d12+Ловкость >= 10+расстояние+укрытие.
Эти формулы теперь доступны в готовом черновике и справочных калькуляторах; полный боевой сценарий ещё не реализован. Правила D&D автоматически не применяются.

По запросу пользователя добавлен готовый набор v1.1 для новых партий и явное применение в существующих. Пять баллов на каждую характеристику — редактируемое начальное предложение. Правила создания (распределение, капы), текущие ресурсы и атаки не автоматизированы. Броня увеличивает максимум HP; поглощение не добавлено из-за противоречия. Урон оружия в калькуляторе вводится уже выпавшим числом: таблица оружия пока не назначается автоматически.
