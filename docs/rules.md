# Исходные правила — черновик, не утверждённая спецификация

Материалы: архив «Настолка.zip»: книга v1.1, NPC codex, Настолка.docx и идентичная Настолка2.docx, мини-игры, 26 PNG. Картотека содержит индивидуальные статблоки, которые нельзя молча пересчитывать.
В v1.1 проверены в том числе формулы Word:
- четыре характеристики: Сила, Ловкость, Телосложение, Харизма;
- HP=(Телосложение+уровень)*2+броня;
- ОД=5+ceil(Ловкость/3), клетка 1 ОД, обычная атака 2 ОД;
- урон=кости оружия+ceil(подходящая характеристика/4);
- ближний: 2d12+Сила против 2d12+Ловкость, реакции защитника;
- дальний: 2d12+Ловкость >= 10+расстояние+укрытие.
Эти формулы ещё не реализованы. Правила D&D автоматически не применяются.
