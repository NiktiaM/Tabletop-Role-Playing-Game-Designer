# Игровой экран 0.5

## Исследование

При открытии партии без активного боя сверху показано «Свободное исследование». Выберите токен, затем щёлкните клетку, перетащите его или используйте стрелки клавиатуры. ОД не ограничивают дальность и не расходуются; можно двигаться и при остатке 0 ОД. Стены, границы, занятые клетки и состояние персонажа учитываются.

Старый флаг tacticalMovement в файле больше не определяет поведение игрового экрана. Для исторического доменного API legacy сохранён явный параметр ручного списания; интерфейс его вне боя не передаёт. Общая movementPolicy используется картой, карточкой и командой движения, чтобы подсветка соответствовала фактическим правилам.

## Начало и завершение боя

Нажмите «Начать бой» в верхней полосе. Укажите название, найдите и отметьте участников, при необходимости внезапность. Нажмите «Начать новый бой», затем «Продолжить» после инициативы. Теперь полоса показывает «Бой активен», название, раунд, текущего участника и ОД. Выбор токена на карте самостоятельно бой не начинает.

Двигаться за ОД может текущий участник выбранного боя. Другие участники ожидают хода. «Закончить ход» передаёт его следующему; «Закончить бой» завершает столкновение. В исследовании оставшиеся ОД перестают ограничивать движение, но HP/ОД не восстанавливаются этим действием.

Если идут независимые бои, верхний список переключает между ними без сброса ресурсов. Участник другого боя получает подсказку выбрать своё столкновение. Персонажи вне всех боёв продолжают исследование без ОД.

## Карточка и действия

В карточке сразу видны режим персонажа и HP, в бою — ОД. Основные сведения находятся в «Обзоре», вещи и способности имеют собственные вкладки. Ручные изменения ресурсов и характеристик находятся во вкладке «Мастер».

Кнопка «Действия / выбрать целью» открывает панель действий и закрывает карточку, чтобы окна не перекрывались. В бою действующий персонаж следует текущему ходу; цель выбирается отдельно. Вне боя выбранный персонаж может применять доступное лечение к себе. Действия разделены на атаку, манёвры, помощь, снаряжение, окружение и мастерские команды. Предпросмотр атаки по-прежнему не меняет ресурсы до применения.

## Карта и инструменты

По умолчанию показывается карта мастера. Отдельная кнопка переключает на личный обзор выбранного персонажа с видимостью и памятью. Область доступного движения подсвечивается только при расходе ОД в бою. В исследовании отображается маршрут без зелёной заливки всей карты.

Часы, проверки и крафт находятся в нижней панели. Инструменты движения и вещей на поле открываются отдельно. «Расстановка мастера» включает явную верхнюю пометку и отдельную кнопку завершения; это вмешательство мастера, а не начало боя. Esc закрывает карточку/боковые панели и отменяет незавершённое размещение, не завершает бой.

Сохранения остаются версии 18. Чтобы пользоваться новым интерфейсом, не требуется повторно применять правила к уже настроенной партии. Windows в этой среде не запускалась; установка и запуск описаны в README.md.
