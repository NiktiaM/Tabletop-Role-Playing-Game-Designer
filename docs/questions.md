# Открытые вопросы

До боя согласовать: броня добавляет HP или поглощает урон (перк предполагает второе); нож 1d6 в книге против 1d4 в сводке NPC; отличаются револьверы; формула HP раннего черновика отличается даже внутри документа.
Порог: предлагается база+max(0, минимум-стат), но требуется подтверждение. Для строгого > вероятности 2d12 при порогах 10/14/17 равны 68,75%/38,19%/19,44%, отличаются от книги.
Не определены: инициатива, стоимость защитнику при ничьей, реакция без ОД, уклонение при отсутствии клетки, восстановление ОД, диагонали и срезание углов, метры на клетку, криты/пробивание/длительность оглушения/добавочная кость сильной атаки.
Перед картой уточнить прямоугольный размер персонажа width×height; перед импортом утвердить JSON/ZIP-контракт. Сложная видимость отложена по решению пользователя.
Вопросы боя не блокируют оболочку.

После выбора разных метров/клетку нужно согласовать физическую скорость и расход ОД: более крупная по метрам клетка не должна случайно ускорять движение. Распознавание локаций по изображению остаётся отдельной возможностью, не реализованной текущими пресетами.

Решение итерации 9: пользователь выбрал 1 ОД/метр и диагональ ×√2 при разных масштабах карт. Срезание углов запрещено. Остаток общий для токенов персонажа; восстановление пока ручное, правила автоматического восстановления при ходах ещё нужны.
