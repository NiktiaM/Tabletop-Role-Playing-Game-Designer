# Инструкции проекта

Общайтесь с пользователем по-русски, объясняйте команды простым языком.
Выполняйте по одной согласованной итерации. Сейчас разрешена итерация 5 (персонажи и токены ширина × высота); не начинайте следующую без согласования.
Читайте docs перед изменениями. Отличайте утверждённые решения от предложений.
TypeScript strict. Игровое ядро не зависит от React, Electron и PixiJS. Формулы системы не зашиваются в UI. Никакого eval и стороннего исполняемого кода в пакетах правил.
Electron: contextIsolation, sandbox, nodeIntegration:false; только ограниченный IPC, проверка входных данных, никаких секретов в репозитории.
Проверки: npm test и npm run build, затем функциональная проверка затронутого сценария. Не выдавайте Linux-проверку за проверку Windows или запуск через браузер за запуск Electron.
Задача уже изолирована: используйте существующий checkout; не создавайте worktree без явного запроса пользователя.
