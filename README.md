# Мастерская партий R Prison

Локальное приложение для мастера настольной ролевой игры. Итерация 2: независимые партии, несколько карт PNG/JPG, масштабирование и перемещение камеры. Сетка, токены и бой ещё не реализованы.

## Запуск

Требуется Node.js 24 LTS и npm. В терминале из каталога проекта:

```sh
npm ci
npm test
npm run build
npm start
```

Для разработки с пересборкой перед запуском: `npm run dev`. После изменения исходников перезапустите команду. Автоматического обновления пока нет.

## Ручная проверка

1. Создайте партию «Побег из Лейквью».
2. Нажмите «Сохранить как…», выберите JSON-файл.
3. Закройте приложение, запустите `npm start`, откройте файл: название должно восстановиться.
4. Создайте другую партию, сохраните другим файлом: первая должна остаться независимой.
5. Попробуйте открыть повреждённый JSON: должно появиться сообщение об ошибке, текущая партия должна сохраниться в окне.
6. Отмените системный диалог: текущая партия не должна измениться.

Windows — первая целевая платформа. Сейчас запускается распакованная версия через Electron; установщик будет позже. Проверки в Linux не заменяют проверку на Windows.

Формат JSON v2 содержит изображения карт и отдельное состояние камеры для каждой карты. Старые партии v1 открываются автоматически; при сохранении создаётся v2, который старая версия приложения не откроет. Перед обновлением сохраните копию старого файла.

## Карты (итерация 2)

1. Создайте или откройте партию, нажмите «Добавить карту…», выберите PNG/JPG.
2. Прокрутите ниже до поля карты. Колесо мыши меняет масштаб относительно курсора; зажатая левая кнопка перемещает карту. «Вписать карту» возвращает её в поле целиком.
3. Добавьте вторую карту и переключайте их через «Текущая карта». У каждой своя камера.
4. Сохраните партию, перезапустите приложение и откройте файл. Обе карты, выбранная карта и положения камер должны восстановиться.
5. Изображения встроены в JSON: исходный PNG/JPG после импорта больше не нужен. Скопируйте JSON в другую папку и проверьте открытие.

Ограничения: до 20 карт, каждая до 15 МБ, до 8192 пикселей по стороне и до 32 млн пикселей. Весь JSON до 100 МБ. Base64 увеличивает размер изображений примерно на треть. Для крупных партий позже предусмотрено отдельное хранилище. Автосохранения пока нет: после импорта и перемещения камеры нажимайте «Сохранить как…».

## Обновление на Windows

Закройте приложение. Скачайте свежий ZIP из GitHub и распакуйте в **новую папку**, чтобы старые `node_modules` не смешались с новыми. Файлы партий оставьте отдельно. В новой папке рядом с package.json откройте cmd и выполните `npm ci`, затем `npm run dev`.

## Дополнительная функциональная проверка

`npm run test:smoke` запускает настоящее окно Electron, создаёт партию, импортирует PNG/JPG, проверяет видимые пиксели карты, камеру, сохранение и открытие после перезапуска. Системные диалоги в тесте подменяются, операции с файлами настоящие. На Linux требуется графический сеанс или Xvfb. Для изолированного CI: `DISPLAY=:99 CI=1 npm run test:smoke`; только в CI передаётся `--no-sandbox`, обычный запуск сохраняет песочницу.

В облачной среде с Node.js 24 загрузке Electron может потребоваться поддержка предоставленного прокси: `NODE_USE_ENV_PROXY=1 npm ci`. Не отключайте TLS-проверку.
